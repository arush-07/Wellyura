# Wellyura v2 design system

## Direction

**The Global Study Atlas** combines editorial typography, maps, route lines and structured data. It intentionally avoids the generic blue-and-white admissions template used by many directories.

## Core palette

- Atlas Ink `#0B1026`
- Warm Paper `#F6F1E7`
- Signal Coral `#FF6846`
- Route Lime `#C9F36A`
- Ocean Blue `#3E5FFF`

## Signature patterns

- Atlas globe hero with coordinate and route motifs
- Persistent comparison dock
- Programme-first result rows
- Editorial country directory
- Visible migrated-data status
- Decision-board student workspace
- Data-quality-first admin interface

## Responsive behavior

The navigation becomes a compact menu, search controls stack, comparison stays accessible, data grids collapse, and detail sidebars move below primary content on smaller screens.
